# Fair-Play Radar

Estimates which of your Chess.com opponents may have cheated, using Chess.com's public API.

- Risk score per opponent: fair-play closures, account age, accuracy vs. rating, rating jumps, win rate
- Engine check: replays games in Stockfish (in your browser) and compares the opponent's engine match and centipawn loss with yours
- Report helper: copies an evidence note and opens the player's profile

Everything runs in the browser; no server, no data stored except a 24-hour cache in your browser.

Scores are heuristics, not proof. Report suspicions to Chess.com rather than accusing players publicly.
